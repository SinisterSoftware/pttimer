# ptTimer 拡張機能

XeFM から ptTimer の録画予約、自動予約条件、番組表を `pttimer://` 仮想フォルダーとして参照する拡張機能です。通常の閲覧と番組表検索に加え、予約の有効／無効切り替えや予約内容の編集もできます。これらの操作は ptTimer のデータベースを変更するため、必要に応じて事前にバックアップしてください。

## 動作条件

- Windows
- XeFM 1.10.0 以降
- ptTimer の `ptTimer.db`
- チャンネル名や番組表の放送局分類も表示する場合は `channel.txt`

この拡張機能は ptTimer のデータベース構造を前提にしています。データベースが見つからない場合、フォルダーは空のように表示されます。読み取り時のデータベースロックなどで取得に失敗した場合、直前の取得結果が残っていれば、それを表示し続けることがあります。

## インストール

XeFM のコマンドラインからインストールします。

```console
xefm ext install github:SinisterSoftware/pttimer
```

インストール後、XeFM の拡張機能設定で後述のデータベースと `channel.txt` の場所を設定してください。更新先を指定する既存の拡張機能メタデータには旧リポジトリ名が残っているため、自動更新先の設定には不整合があります。手動でインストールまたは更新する場合は、上記の現行リポジトリを指定してください。

## 設定

拡張機能の設定項目は次のとおりです。設定値は `pttimer/settings.py` の既定値で初期化されますが、既定の `D:\DTV\...` が実際の保存場所と異なる場合は、XeFM の拡張機能設定で実際のパスに変更してください。

| 設定 | 内容 |
| --- | --- |
| `PTTIMER_DB_PATH` | `ptTimer.db` のフルパス。必須です。空欄の場合は環境変数 `PTTIMER_DB_PATH`、続いて `%ProgramFiles(x86)%\ptTimer\ptTimer.db`、`%ProgramFiles%\ptTimer\ptTimer.db` を探します。 |
| `CHANNEL_TXT_PATH` | `channel.txt` のフルパス。放送局名・放送種別の解決に使います。ファイルの変更は自動的に読み直されます。 |
| `SERVICE_NAME_MAP` | SID（数値）から表示用チャンネル名への手動対応表。`channel.txt` の名前より優先されます。 |
| `CHANNEL_TYPE_OVERRIDE` | SID（数値）から放送種別（`地デジ`、`BS`、`CS`）への手動対応表。`channel.txt` からの推定より優先されます。 |
| `INCLUDE_PAST_RESERVATIONS` | `True` にすると終了済みの録画予約も一覧に含めます。既定値は `False` です。 |
| `EPG_DAYS_AHEAD` | 番組表に表示する期間（日数）。既定値は `7` です。 |
| `EDITOR_COMMAND` | 予約編集に使うエディターのコマンドと引数のリスト。既定値は `["vim"]` です。GUI エディターでは、終了まで待つためのオプション（例：`["code", "--wait"]`）を指定してください。 |

`channel.txt` はCSVとして読み込まれます。放送局名などを解決するため、各行の2列目（ONID/TSID、16進数）、5列目（番組表取得設定。`0` が有効）、6列目（SID、16進数）、7列目（局名）が使用されます。文字コードはUTF-8、次にCP932を試します。

地デジ／BS／CSの判定はONID/TSIDの値による推定です。放送種別が誤っている場合や「不明」になる場合は、`CHANNEL_TYPE_OVERRIDE` でSIDごとに補正してください。番組表の局フォルダー一覧には、`channel.txt` で番組表取得が有効な局だけが表示されます。

## 使い方

XeFM の場所入力やパス移動で、次のURIを開きます。

```text
pttimer://
```

ルートには「予約」「番組表」「自動予約」が表示されます。

### 録画予約

```text
pttimer://予約/
```

予約は開始時刻順のファイルとして表示されます。ファイル名はおおむね `YYYY-MM-DD_HH-MM_番組名.txt` です。予約ファイルを開くと、番組名、チャンネル、開始・終了時刻、録画時間、状態、備考、番組概要・詳細（データがある場合）、予約IDを確認できます。ファイル名に使えない文字は `_` に置き換えられます。

- 既定では終了済みの予約は一覧に出ません。設定 `INCLUDE_PAST_RESERVATIONS` で変更できます。
- 無効化された予約は隠しファイル属性で表示されます。表示されない場合は XeFM で隠しファイルを表示してください。無効な予約には一覧上で赤い `×` が付きます。
- 仮想ファイルのサイズは録画時間（分）×1 MiB、更新日時は予約開始時刻を表す表示用の値です。実ファイルのサイズや更新日時ではありません。

#### 予約の有効／無効切り替え

予約ファイルに XeFM 標準の削除アクション（`delete_files`）を実行すると、予約を削除せず有効／無効を切り替えます。ptTimer のデータベースで `flg1` を有効時は `0`、無効時は `4` に更新します。自動予約条件や番組表に対する削除操作はできません。

#### 予約の編集

予約ファイルに対して `pttimer.edit` アクションを実行すると、設定された外部エディターで編集用テキストが開きます。編集して保存できるのは次の項目です。

- `番組名`
- `チャンネル`
- `開始`
- `終了`

日時は `YYYY-MM-DD HH:MM:SS` 形式で入力します。チャンネルは `channel.txt` の表示名を指定します。同名の局が複数ある場合や局名を解決できない場合は、`SID:12345` のようにSIDを指定してください。終了時刻は開始時刻より後である必要があります。予約IDは変更・削除しないでください。状態、備考、番組概要、番組詳細など、上記以外の項目は表示のみで、編集内容は保存されません。

変更を保存するとデータベースを更新し、予約一覧を再読み込みします。ptTimer が起動中の場合は再読み込み通知を送ります。

### 自動予約条件

```text
pttimer://自動予約/
```

ptTimer の自動予約条件（`t_autoprog`）が一覧表示されます。ファイルを開くとキーワード、対象チャンネル、ジャンル、時間帯、設定フラグを確認できます。自動予約条件は参照専用です。

### 番組表

```text
pttimer://番組表/
```

番組表には、現在時刻から `EPG_DAYS_AHEAD` 日先までの終了していない番組が表示されます。次の3種類の見方があります。

**チャンネル別**

```text
pttimer://番組表/チャンネル/地デジ/局名/
pttimer://番組表/チャンネル/BS/局名/
pttimer://番組表/チャンネル/CS/局名/
```

放送種別、局の順に選ぶと、その局の対象期間内の番組が開始時刻順に表示されます。

**日付別**

```text
pttimer://番組表/日付/YYYY-MM-DD/放送種別/局名/
```

日付を選び、放送種別、局の順に絞り込みます。選択できる日付は番組データがある日付です。

**キーワード検索**

```text
pttimer://番組表/検索/キーワード/
```

番組名、概要、詳細を対象に、大文字・小文字を区別しない部分一致で検索します。半角または全角スペースで複数語を区切ると、すべての語を含む番組だけが結果に残ります（AND検索）。たとえば `野球 夜` は「野球」と「夜」の両方を含む番組を探します。ローマ字から日本語を探すMigemo検索には対応していません。

検索語を入力する `pttimer.epg-search` アクションもあります。manifest では `Alt-G` がキー候補として提示されていますが、既存のキー割り当てを上書きするものではありません。必要に応じてXeFMのキー設定でアクションを割り当ててください。検索入力中の `/` はパス区切りとして扱われるため、スペースに置き換えられます。

番組表の仮想ファイルを開くと、番組名、チャンネル、放送種別、開始・終了時刻、放送時間、番組概要・詳細を確認できます。

## 一覧の表示

pttimer の一覧では通常のサイズや更新日時の代わりに、開始時刻と録画／放送時間を表示します。チャンネル列と状態マーカーも追加されます。設定によって追加列が見えない場合は、XeFMの表示レイアウト設定を確認してください。無効予約は赤い `×` で示され、有効予約にはマーカーが付きません。

## トラブルシューティング

| 症状 | 確認事項 |
| --- | --- |
| 予約や番組表が空 | `PTTIMER_DB_PATH` が実在する `ptTimer.db` を指しているか確認してください。既定パスは環境によって異なります。 |
| 局名が `SID:...` と表示される | `CHANNEL_TXT_PATH` が正しい `channel.txt` を指しているか、SIDがファイルに含まれているか確認してください。 |
| 番組表の局や放送種別が見つからない | `channel.txt` の5列目の取得設定が `0` か確認してください。放送種別の推定が合わない場合は `CHANNEL_TYPE_OVERRIDE` を設定してください。 |
| 予約編集が始まらない | `EDITOR_COMMAND` とその引数を確認してください。GUIエディターには終了まで待つオプションが必要です。 |
| 予約編集でチャンネルのエラーが出る | `channel.txt` 上の局名、または `SID:数値` を指定してください。局名が重複する場合はSIDを使ってください。 |
| 一覧が更新されない | データは短時間キャッシュされます。SQLiteのロックなどで読み込みが失敗すると、直前の結果が表示され続ける場合があります。 |
