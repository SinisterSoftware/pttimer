# ptTimer

XeFM extension to browse ptTimer reservations and EPG data in a `pttimer://` virtual folder, with actions for editing and enabling/disabling reservations.

Install with `xefm ext install github:SinisterSoftware/pttimer`.

日本語の詳しい使い方は [README.ja.md](README.ja.md) をご覧ください。

For development, run `xefm ext check .` and `python -m pytest tests`.
